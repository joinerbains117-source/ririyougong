# 日日有功

为个人使用制作的免费移动端习惯打卡工具。无需账户，没有广告或订阅。适合在 iPhone Safari 添加到主屏幕使用。

## 使用

1. 在 Safari 打开发布网址，点击「分享 → 添加到主屏幕」。
2. 从桌面图标打开；首次加载需联网，离线缓存完成后支持断网打开。
3. 点击任务右侧「＋」完成，点击「✓」撤销；可写当日收获。
4. 「习惯」中可修改目标、开始日期和重复星期；将开始日期设为过去即可补记此前记录。
5. 「记录」查看月历、选择过去日期补记；不支持提前打卡。
6. 每周到「我的」导出 JSON 备份，并在「文件」或 iCloud 云盘确认保存。换手机时可从备份恢复。

## 默认习惯

英语 15 分钟、锻炼 20 分钟、陪宝宝学习 20 分钟、道家文化 10 分钟、学习 AI 20 分钟、练字 10 分钟。这些是可修改的初始建议，不是必须全部完成的要求。

## 数据与边界

- 所有个人任务、笔记、打卡仅保存在当前设备的网站存储中，不上传 GitHub 或服务器。
- 不同设备或不同浏览器之间不自动同步；Safari 与主屏幕应用的数据共享行为取决于系统，请固定从同一入口使用。
- 清理网站数据、卸载或换机可能丢记录；导出只是发起下载，请确认文件已保存。
- 导入经过格式校验，确认后替换本机记录，导入前先备份。
- 归档从今天起停止安排任务，保留旧记录；重新开始创建新习惯。修改重复星期和开始日期会重新计算相关历史统计。
- 连续次数按计划执行日计算，休息日不打断，今天尚未完成时保留此前连续次数。
- 后台定时推送、系统组件和健康数据同步不在本版范围内。提醒可在 iPhone「提醒事项」中设置。
- 应用页面和代码公开；其他访问者获得自己的独立本地数据。

## 免费运行与维护

纯 HTML/CSS/JavaScript，通过 GitHub Pages 公共仓库免费静态托管，无独立域名、数据库、付费 API 或服务器。本项目不将免费托管描述为永远可用的商业承诺。服务政策变化时可迁移至其他静态托管或本地运行。

本地运行：`python3 -m http.server 8765`，再打开 `http://localhost:8765`。不要直接用 file:// 打开，离线缓存需要 HTTPS 或 localhost。

检查核心逻辑：`node test-core.cjs`。
