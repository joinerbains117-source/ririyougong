# 日日有功

为个人使用制作的免费移动端习惯打卡工具。无需账户，没有广告或订阅。适合在 iPhone Safari 添加到主屏幕使用。

## 使用

1. 在 Safari 打开发布网址，点击「分享 → 添加到主屏幕」。
2. 从桌面图标打开；首次加载需联网，离线缓存完成后支持断网打开。
3. 点击任务右侧按钮填写实际完成量，达到目标的 80% 即算完成；再次点击可修改或清除，收获笔记独立保留。
4. 「习惯」中可自定义正数目标和单位（例如 10 分钟、10 次），也可修改开始日期和重复星期；将开始日期设为过去即可补记此前记录。
5. 「记录」查看月历、选择过去日期补记；不支持提前打卡。
6. 「看板」分为日完成和月完成。日完成显示当天已完成/当天任务数及日完成率；月完成显示当月每日完成率的平均值、统计天数、全部完成天数和每日明细。
7. 每周到「我的」导出 JSON 备份，并在「文件」或 iCloud 云盘确认保存。换手机时可从备份恢复。

## 默认习惯

英语 15 分钟、锻炼 20 分钟、陪宝宝学习 20 分钟、道家文化 10 分钟、学习 AI 20 分钟、练字 10 分钟、不看短视频 1 天。这些是可修改的初始建议，不是必须全部完成的要求。

## 数据与边界

- 所有个人任务、笔记、打卡仅保存在当前设备的网站存储中，不上传 GitHub 或服务器。
- 不同设备或不同浏览器之间不自动同步；Safari 与主屏幕应用的数据共享行为取决于系统，请固定从同一入口使用。
- 清理网站数据、卸载或换机可能丢记录；导出只是发起下载，请确认文件已保存。
- 导入经过格式校验，确认后替换本机记录，导入前先备份。
- 归档从今天起停止安排任务，保留旧记录；重新开始创建新习惯。修改重复星期和开始日期会重新计算相关历史计划统计；每条完成记录保存当时的目标及单位，后续修改目标不会改变历史达标判定。
- 连续次数按计划执行日计算，休息日不打断，今天尚未完成时保留此前连续次数。
- 后台定时推送、系统组件和健康数据同步不在本版范围内。提醒可在 iPhone「提醒事项」中设置。
- 应用页面和代码公开；其他访问者获得自己的独立本地数据。

## 免费运行与维护

纯 HTML/CSS/JavaScript，通过 GitHub Pages 公共仓库免费静态托管，无独立域名、数据库、付费 API 或服务器。本项目不将免费托管描述为永远可用的商业承诺。服务政策变化时可迁移至其他静态托管或本地运行。

本地运行：`python3 -m http.server 8765`，再打开 `http://localhost:8765`。不要直接用 file:// 打开，离线缓存需要 HTTPS 或 localhost。

检查核心逻辑：`node test-core.cjs` 与 `node --test test-progress.cjs`。

## 2.0 更新规则（2026-10-20）

- 每项任务的数值目标和单位可以分别修改；实际完成量必须手工填写，达到目标的 80%（含）判定为完成，支持小数和超额完成。未填或低于 80% 为未完成。
- 「不看短视频」初始为每天 1 天，以 1（当天没看）或 0（当天看过）填写。新任务从升级当天开始安排，避免影响此前的月度计划分母。
- 2.0 曾按累计任务项次显示月度达标率，已在 2.1 替换为下述日/月完成口径，避免把累计项次当成每天任务数。
- 旧版数据自动升级。已完成标记保持达标并标注「旧版达标记录」，由于旧版没有采集实际完成量，数值按旧目标折算，仅为兼容旧标记；可补录真实数值。
- 升级前的原始记录留在同一设备的 `ririyougong.before-v2` 存储项，升级不清空网站数据。旧版与新版 JSON 备份均可导入；新版备份请用新版恢复。
- 离线资源按整套版本缓存，首次联网升级后重新打开应用使用新版。请勿通过清除网站数据来刷新应用，以免删除记录。
- 验证：数值边界、旧数据与旧备份迁移、历史目标快照、月度分母与休息日；隔离 Chromium 浏览器完成录入/修改/清除、笔记、看板、导入导出、离线和旧离线缓存升级验证。真实 iPhone Safari 仍需设备端体验确认。


## 2.1 看板修正（2026-10-21）

- 日完成率 = 当天已达标任务数 / 当天安排任务数。例如每天 7 项、完成 5 项，显示 5/7 和 71.4%。
- 月完成率 = 当月各个统计日期的日完成率平均值（先用未取整的日比例求平均，再保留一位小数）。每天任务数相同时等同于累计完成数 / 每日任务数与统计天数的乘积。
- 仅统计开始使用后、截至今天有任务安排的日期。没有填写的计划日仍以 0% 计入，未来日期和无任务的休息日不计入；不虚构开始使用之前的任务。
- 看板默认展示日完成，可切换月完成。月视图有每天的完成项数/当天任务数，点击可回到该日日完成详情。累计项次不再显示为看板分母。
- 保留个人记录、目标及单位、80% 单项达标和备份格式。历史上若某日仅安排了 6 项，按实际 6 项展示，不伪造第 7 项。
- 核心完整测试：`node --test`；日/月口径回归：`test-dashboard.cjs`。
